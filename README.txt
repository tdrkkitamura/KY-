現場KY撮影・分析画像出力アプリ　試作Ver.1
1. GitHubに新規公開リポジトリ ky-check を作成
2. このフォルダの index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png, icon-512.png をアップロード
3. Settings → Pages → Deploy from a branch → main /(root) → Save
4. https://<GitHubユーザー名>.github.io/ky-check/ にiPhone Safariでアクセス
5. Safariの共有 → ホーム画面に追加
注意: OCRはTesseract.js 日本語モデルの外部ダウンロードが必要。手書き精度は保証されない。危険予測はルール方式で生成AIではない。必ず人が確認。
